# ATM Performance Analysis
[description] 
This dashboard analyzes ATM transaction activities across different states, banks, and transaction types. The analysis focuses on customer transaction behavior, regional performance, ATM operational efficiency, transaction trends, and banking network performance to identify key insights and support data-driven decision-making.

Data Preparation and Quality Enhancement with Excel-  Leveraged Microsoft Excel to perform comprehensive data cleaning, transformation, and tabulation, ensuring data accuracy, consistency, and readiness for advanced analysis. Applied data validation techniques, handled missing values, removed duplicates, and structured datasets to support reliable decision-making.

Advanced Data Analysis and Query Optimization with SQL - Utilized SQL to extract, filter, and analyze large datasets, uncovering key performance trends across multiple dimensions, including transaction year, transaction amount, card issuer, ATM owner, fraud status, and cash dispense status. Developed targeted queries to generate actionable insights, identify patterns, and support data-driven business decisions.

ATM Performance Monitoring and Business Intelligence with Power BI - Developed interactive Power BI dashboards to analyze ATM transaction data, monitor operational performance, and identify key trends. Created visual reports to track transaction volumes, cash dispense success rates, fraud incidents, card issuer activity, and ATM owner performance, enabling data-driven operational and business decisions.
